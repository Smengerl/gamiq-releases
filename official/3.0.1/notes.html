Prepares the units of v3.0 for several systems on one WiFi, which v3.1 will bring, and finishes the result line of the dev commands. Nothing changes in how the clock is operated. Works with units of the same MAJOR version; update every unit of v3.0.0 to this version before a unit of v3.1 joins the same WiFi.
Fixes and changes6
A Master of another system is no longer taken for a Master of the own one when it is found by mDNS: a unit neither joins it nor yields its role to it.
#68
A state with a game mode this version does not know keeps the Master heard instead of being dropped, so a Slave no longer becomes a second Master when a later version adds a mode.
#68
The contract of the unit link says what a receiver does with what it does not know, fixes the format of the system id and reserves the names v3.1 will use.
#68
For people who build: every dev command needs an id, and its eng trace line is the end of the command with ok, refused, busy or failed: after the upload for a snapshot and a crash dump, after the trial of the new image for an image. The bench waits for that line. Breaks the engineering route of v3.0.0: a command without an id is answered with 400.
#186
The state the Master sends carries the colours of the units of the system (units), so a phone can show them as colour dots.
#68
For people who build: the test rig no longer counts a unit as off or absent when a trace line is lost; the trace is UDP.
