The firmware is split into a platform and a game type: the platform carries WiFi, the unit link, the web server, update and pairing, the game type (here the basketball shot clock) carries the rules, its screens and its part of the page. The first game type behaves as before; later ones can reuse the platform. This is a MAJOR step: the unit link and the REST API are version 4, units of v3.x and v4.0.0 do not play together. Update every unit of a system to v4.0.0.
What is new4
Platform and game typethe sources are platform/ and games/<game type>/, the page is a shell in frontend/platform/ and a game part in frontend/games/<name>/. A script (check_repo.py) keeps the platform free of any game type, the shell included.
