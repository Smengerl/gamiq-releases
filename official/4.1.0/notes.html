GAMiq, basketball complete: the shot clock system becomes a display system for games and sports, and basketball is its first game type: besides the shot clock, a unit can show the game clock with the period strips and the possession arrow, or the score. Works with units of the same MAJOR version (4).
Highlights5
**Jobs (Rolle) per unit:** shot clock, game clock + possession arrow, score home + guest, score home, score guest. A joining unit takes the first free position of the default order; the jobs, the game type and its settings (periods 4 or 8, length of a period, overtime) are set on the phone in the Spiele popup (Spielart › Details, the unit's row) and are locked while a game is held. A job only one unit can hold is swapped after a question.
Phone page by partsthe shot clock, the game clock (strips, ±1 s and ±0.1 s in the last minute, Zeit setzen, next period, end of the game, a horn at 0) and the score (+2, +1, +3, −1) with the Wechselpfeil. Below 768 px one part with a strip of tabs, from 768 px all parts side by side. A part no unit shows has no controls. The score goes up to 999.
Panelsa screen per job (game clock with the period strips and the arrow, the score in one line or one score large, the shot clock goes dark with less game time left) and the flip number on a change of score.
GAMiqa new logo on the start screen, the hotspot GAMiq_<colour>_<id>, the page title and the texts (a unit is a unit; the shot clock is one job).
Prepared for further game typesthe platform and a game type are apart (platform/, games/<name>/), and python3 -m ship newgame <name> makes the folders of a new one. The guide has a chapter for the basics, one for the game type and one for several games and game types.
Fixes and changes4
A job and a game type can only change while no game is held; the phone says why.
The page loads the parts of a game one at a time, so three phones do not starve the Master of connections.
A Slave's period lengths follow the settings; game_set cannot wrap for a huge value; the horn is fetched when the game clock part loads first.
The page ships without indentation and comments (about 14.3 KB gzip).
Changes to know3
The host name of a unit is now gamiq-<id>.local(it was shotclock-<id>.local). A bookmark or a home automation that uses the old name stops working; there is no transition. The QR code on the panel uses the IP address and is not affected; the units find each other by their services, not by the host name.
Tested with up to three phoneson one system; a fourth works but is outside what is tested.
The boot line SHOTCLOCK id=…, the release site and the repositories keep their names.
